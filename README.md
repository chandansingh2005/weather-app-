# Weather App 🌦️

## 📌 Description
This is a simple Weather Application built using HTML, CSS, and JavaScript. It fetches real-time weather data using an API.

## 🚀 Features
- Search weather by city
- Displays temperature, humidity, and condition
- Simple and clean UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Weather API

## 📚 What I Learned
- API fetching using JavaScript
- DOM manipulation
- Handling user input
